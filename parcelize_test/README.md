# Parcelize Test Module

This module demonstrates Android's `@Parcelize` annotation and `Parcelable` interface for efficiently serializing and passing complex data objects between Android components (Activities, Fragments, Intents, and Bundles).

## Key Topics
- `@Parcelize` annotation usage
- Custom Parcelable implementations
- Passing complex objects via Bundles and Intents
- Performance comparison with Serializable
