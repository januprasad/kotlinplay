# RxAndroid Java Module

This module demonstrates reactive programming in Android using RxJava 3 and RxAndroid. It covers Observables, Flowables, operators (map, flatMap, filter), schedulers for thread management, and reactive stream lifecycle handling.

## Key Topics
- Observables, Single, Maybe, and Completable
- RxJava operators and transformation
- Schedulers (`subscribeOn`, `observeOn`)
- Disposing subscriptions and preventing memory leaks
