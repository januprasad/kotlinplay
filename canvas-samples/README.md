# Canvas Samples Module

This module demonstrates custom 2D graphics rendering in Android using `Canvas` and `Paint`. It covers custom View creation, drawing geometric shapes, paths, bitmaps, manipulating matrix transformations, and implementing smooth graphical animations.

## Key Topics
- Custom View drawing and `onDraw()` lifecycle
- `Canvas` and `Paint` API usage
- Paths, shaders, and gradients
- Interactive gesture drawing and animations
