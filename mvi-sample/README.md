# MVI Sample Module

This module demonstrates the Model-View-Intent (MVI) architectural pattern with unidirectional data flow (UDF). It illustrates immutable state management, user intent processing, side-effect handling, and reactive UI rendering in Jetpack Compose.

## Key Topics
- Unidirectional Data Flow (UDF) architecture
- Immutable state representation
- Intent processing and reducer pattern
- Jetpack Compose integration with MVI
