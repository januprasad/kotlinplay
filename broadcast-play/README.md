# Broadcast Play Module

This module demonstrates Android BroadcastReceivers, covering both statically declared receivers in the manifest and dynamically registered runtime receivers. It illustrates how to send and receive custom system or application intents for decoupled event handling.

## Key Topics
- Static vs. Dynamic `BroadcastReceiver` registration
- Custom Intent creation and filtering
- LocalBroadcastManager and modern broadcast patterns
- Security considerations for broadcasts
