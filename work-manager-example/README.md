# Work Manager Example Module

This module demonstrates Android WorkManager API for dependable, persistent background work execution. It covers one-off and periodic work requests, input/output data passing, constraints, and work chaining.

## Key Topics
- `WorkRequest` (OneTimeWorkRequest, PeriodicWorkRequest)
- Defining `Worker` and `CoroutineWorker`
- Work constraints (Network, Battery, Charging)
- Work chaining and observation (`WorkInfo`)
