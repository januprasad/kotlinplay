# StateFlow SharedFlow Module

This module demonstrates Kotlin Coroutines `StateFlow` and `SharedFlow` for reactive state management and event emission. It covers hot flows, state sharing in ViewModels, and collecting flows safely in UI lifecycles.

## Key Topics
- `StateFlow` for state management
- `SharedFlow` for one-time event emission (events vs. state)
- Lifecycle-aware flow collection in UI
- Cold to hot flow transformations
