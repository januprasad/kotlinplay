# Hilt Example Module

This module demonstrates dependency injection in Android using Hilt (built on Dagger). It covers standard Hilt setup, component annotations (`@AndroidEntryPoint`, `@HiltAndroidApp`), module definitions, constructor injection, and ViewModel injection.

## Key Topics
- Dagger Hilt setup and annotations
- Scoped dependencies and component lifetimes
- Injecting dependencies into Activities, Fragments, and ViewModels
- Providing custom modules and bindings
