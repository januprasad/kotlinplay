# Crypto Module

This module demonstrates Kotlin and Java cryptography APIs for secure data handling. It covers secure hashing algorithms, symmetric and asymmetric encryption, decryption, key generation, and secure storage practices.

## Key Topics
- Message hashing (SHA, MD5, etc.)
- Symmetric encryption (AES) and asymmetric encryption (RSA)
- KeyStore integration and secure key management
- Encoding and decoding utilities
