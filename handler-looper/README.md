# Handler Looper Module

This module demonstrates low-level Android concurrency using `Handler`, `Looper`, and `MessageQueue`. It illustrates how messages and runnables are queued and processed across threads, bridging background worker threads with the main UI thread.

## Key Topics
- `Looper` and `MessageQueue` mechanics
- Posting `Runnable` tasks and sending `Message` objects
- Inter-thread communication
- Preventing memory leaks with handlers
