# Alarm Manager Module

This module demonstrates the usage of the Android `AlarmManager` API for scheduling system-level alarms, executing periodic background tasks, and handling alarm triggers using `BroadcastReceiver`. It highlights best practices for working with exact and inexact alarms across different Android API versions.

## Key Topics
- `AlarmManager` configuration (exact vs. inexact alarms)
- PendingIntents for alarm triggers
- Handling background broadcasts with `BroadcastReceiver`
- Managing power-saving modes (Doze mode, App Standby)
