# Coroutines Module

This module demonstrates Kotlin Coroutines for asynchronous and non-blocking programming. It covers coroutine builders (`launch`, `async`), dispatchers (`Dispatchers.IO`, `Main`, `Default`), structured concurrency, exception handling, and cancellation mechanisms.

## Key Topics
- Coroutine builders and scopes
- Dispatchers and context switching
- Structured concurrency principles
- Exception handling in coroutines
